## 🔧 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **框架**: Bootstrap 5
- **图标**: Bootstrap Icons
- **后端**: Node.js + Express.js（需要单独启动）
- **数据库**: MySQL
- **OCR服务**: 通义千问API
