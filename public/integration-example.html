2. 高级配置

使用回调函数处理上传结果

高级特性： 自定义最大数量、文件类型、大小限制、上传前后回调等 
// 高级配置示例
const uploader = new MultiImageUploader({
  maxImages: 6,              // 最多6张
  allowedTypes: ['image/jpeg', 'image/png'],  // 仅支持JPG和PNG
  maxSize: 3 * 1024 * 1024, // 3MB限制

  // 自定义选择器
  container: '#custom-container',
  uploadButton: '#custom-upload-btn',

  // 上传前回调
  onBeforeUpload: async (images) => {
    console.log('准备上传', images.length, '张图片');
    // 这里可以做额外的验证
  },

  // 上传成功回调
  onSuccess: (data) => {
    console.log('上传成功:', data);
    // 发送到后端或更新UI
    sendToBackend(data);
  },

  // 上传失败回调
  onError: (error) => {
    console.error('上传失败:', error);
    // 显示错误提示
    showError('上传失败，请重试');
  }
});

3. API 文档

方法 参数 说明
deleteImage(id) id: 图片ID 删除指定图片
clearAll() 无 清空所有图片
getImages() 无 获取已选图片列表
getOutputData() 无 获取输出数据（格式化后的）
输出数据格式
{
  images: [
    {
      name: "essay.jpg",
      size: 1024000,
      url: "blob:http://...",
      base64: "data:image/jpeg;base64,/9j/4AAQ..." // 可选
    }
  ],
  total: 3,
  timestamp: "2024-01-01T12:00:00.000Z"
}

4. 集成到现有页面

演示如何将多图上传集成到现有的作文提交功能中：

步骤1：在HTML中添加上传区域
<form id="essay-form">
  <div class="mb-3">
    <label>作文题目</label>
    <input type="text" class="form-control">
  </div>

  <!-- 多图上传区域 -->
  <div class="mb-3">
    <label>手写作文（拍照）</label>
    <div id="essay-images-uploader">
      <!-- 上传组件将在这里初始化 -->
    </div>
  </div>

  <button type="submit" class="btn btn-primary">
    提交作文
  </button>
</form>
步骤2：初始化和处理提交
<script>
// 初始化上传组件
const essayUploader = new MultiImageUploader({
  container: '#essay-images-uploader',
  maxImages: 5
});

// 表单提交处理
document.getElementById('essay-form').addEventListener('submit', async (e) => {
  e.preventDefault();

  // 获取表单数据
  const formData = {
    title: e.target.title.value,
    content: e.target.content.value,
    images: essayUploader.getOutputData()
  };

  // 发送到后端
  const response = await fetch('/api/essay/submit', {
    method: 'POST',
    body: JSON.stringify(formData)
  });

  // 处理响应
  // ...
});
</script>
